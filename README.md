# Товарная структура и географическое распределение внешней торговли Японии, 2000–2025 гг.

Код и данные к информационно-аналитической справке по дисциплине «Международные экономические отношения» (МГИМО МИД России, кафедра международных экономических отношений и внешнеэкономических связей им. Н.Н. Ливенцева).

Автор: Толкушкин А. М., 2026.

Все числа, приведённые в справке, получены с помощью скриптов из этого репозитория. Любой расчёт можно проверить или воспроизвести.

## Источник данных

Данные получены из базы UN Comtrade (https://comtradeplus.un.org/) через API. Используется отчётность Японии (код 392) в текущих долларах США по классификации HS (на уровне двух знаков соответствует главам ТН ВЭД).

| Набор | Содержание | Период |
|---|---|---|
| `data/annual_partners.csv` | экспорт и импорт Японии по всем странам-партнёрам | 2000–2024 |
| `data/annual_hs2.csv` | экспорт и импорт Японии по 96 главам HS | 2000–2024 |
| `data/bilateral_hs2.csv` | торговля с 16 ключевыми партнёрами по главам HS | 2005, 2015, 2024 |
| `data/monthly.csv` | помесячная торговля с миром и шестью партнёрами | 2010–2025 |
| `data/world_hs2.csv` | мировой экспорт по главам HS (для индекса RCA) | 2005, 2024 |
| `data/ref_partners.json` | справочник кодов стран UN Comtrade | |

Исходные ответы API (JSON) в репозиторий не включены. Скрипт `fetch_comtrade.py` загружает их заново.

## Методика

- Доли товарных групп и стран-партнёров, сальдо по регионам.
- Индекс Херфиндаля–Хиршмана (сумма квадратов долей в %, от 0 до 10 000) для товарной и географической концентрации.
- Индекс выявленных сравнительных преимуществ Балассы, RCA = (доля главы в экспорте Японии) / (доля главы в мировом экспорте).
- Индекс внутриотраслевой торговли Грубела–Ллойда, GL = 2·min(X, M) / (X + M), суммированный по главам HS для каждого партнёра.
- Ивент-анализ, то есть сравнение среднемесячного экспорта и импорта за шесть месяцев после события и за шесть месяцев до него.

Особенности данных:

- Тайвань в UN Comtrade обозначен как «Other Asia, nes» (код 490).
- ЕС-27 рассматривается в постоянном составе за весь период.
- Гл. 99 (неклассифицированные товары) исключена из расчёта RCA.
- Мировой экспорт 2024 г. рассчитан по 148 отчитавшимся странам (в 2005 г. по 172).
- Годовые данные за 2025 г. на момент расчётов не опубликованы, поэтому 2025 г. рассчитан как сумма помесячных данных.

## Структура репозитория

```
code/
  fetch_comtrade.py   загрузка данных из UN Comtrade API
  build_tables.py     преобразование ответов API в таблицы data/*.csv
  analyse.py          расчёт показателей, таблицы tables/*.csv, рисунки figures/*.png, сводка results.md
  export_excel.py     сборка приложения Приложение_Япония_торговля.xlsx
data/                 подготовленные данные
tables/               итоговые таблицы расчётов
figures/              рисунки справки
results.md            сводка всех рассчитанных показателей
Приложение_Япония_торговля.xlsx   приложение к справке (таблицы и рисунки)
```

## Как воспроизвести

Нужны Python 3.10+ и `curl`.

```bash
pip install -r requirements.txt
```

Для расчётов по готовым данным достаточно двух команд.

```bash
python3 code/analyse.py
python3 code/export_excel.py
```

Чтобы загрузить данные заново, нужен бесплатный ключ UN Comtrade. Зарегистрируйтесь на https://comtradedeveloper.un.org/, подпишитесь на продукт «comtrade - v1» и сохраните основной ключ в файл `~/.comtrade_key`. Ключ хранится вне репозитория и не публикуется. Без ключа скрипт использует открытый API с ограничением числа запросов, и загрузка займёт несколько часов.

```bash
python3 code/fetch_comtrade.py all
python3 code/build_tables.py
python3 code/analyse.py
python3 code/export_excel.py
```
